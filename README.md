# aSell

A Minecraft plugin (Paper/Spigot) that lets players quickly and easily sell
ores and other items from their inventory.

> 🚧 Work in progress, created by [airton-web](https://github.com/airton-web)
> as part of my journey learning Java plugin development.

## Planned features

- Sell ores and other items (crops, mob drops, etc.)
- Configurable prices per item
- Customizable messages
